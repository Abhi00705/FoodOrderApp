# 🍔 Food Order App

A modern and responsive food ordering web application built using React and modern frontend technologies. The application allows users to browse food items, manage a cart, and experience smooth navigation with efficient state management.

---

## 🚀 Features

* 🍽️ Browse and explore food items
* 🛒 Add, remove, and update items in the cart
* 🔄 Real-time state management using Redux Toolkit
* 🔍 Seamless navigation with React Router
* 🎨 Fully responsive UI using Tailwind CSS
* ⚡ Fast development and build with Vite

---

## 🛠️ Tech Stack

### 🔹 Frontend

## ⚙️ Installation & Setup

```id="fs2"

```

### 2. Install dependencies

```id="fs3"

```

### 3. Run the project

```id="fs4"

```

## 🧠 Application Flow

* Food items are displayed using reusable React components
* Users can interact with items and manage their cart
* Redux Toolkit handles global state for cart operations
* React Router enables smooth navigation between pages
